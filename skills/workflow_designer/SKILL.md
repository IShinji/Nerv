# Workflow Designer

Use this skill when a task repeats, uses multiple tools, or needs a stable handoff between agents.

## Guidance

- Reuse an existing shared workflow before drafting a new one.
- Draft a new workflow when the steps, tool sequence, and success criteria are clear.
- Keep workflow steps concrete and executable.
- After drafting, send it to the review queue instead of publishing it directly.
- Shared workflows should be generic enough for reuse, but specific enough that another agent can execute them consistently.
